# Runbook: Migrate to the shared bot-identity hook (this PR, #39)

## What this is

This repo moved off its own hand-copied bot-identity implementation and onto
the shared, user-level machinery under `~/.claude` — one GitHub App
(`mccarthycode-claude-agent[bot]`, id `308820401`), one hook, one allowlist
(`~/.claude/LIFEOS/USER/CONFIG/bot-identity.json`), one verifier, and a `gh`
wrapper (`~/.claude/LIFEOS/TOOLS/gh-bot`) for writes — replacing the
per-repo `mmio-claude-agent[bot]` setup built up across #20, #22, #25, #27,
and #31.

Four repos each carried a hand-copied version of `BotIdentity.hook.sh`, so
the same classes of bug got rediscovered and fixed one copy at a time —
Curated-Compatibility's `docs/runbooks/1.md`, `26.md`, and `29.md`, and
School-Shop-LA's `docs/runbooks/14.md` (the `$CLAUDE_PROJECT_DIR`-empty
failure that motivated moving off per-repo hardcoded hook paths entirely).
This PR retires mmio's copy in favor of the shared version.

## What changed

- Deleted `.claude/hooks/BotIdentity.hook.sh`, its `.claude/settings.json`
  registration, and the token-minting scripts it depended on:
  `scripts/gh_app_exec.sh`, `scripts/gh_app_pr_create.sh`,
  `scripts/gh_app_token.ts`.
- Added `mccarthycode/mmio` to the shared allowlist in
  `~/.claude/LIFEOS/USER/CONFIG/bot-identity.json`.
- `AGENTS.md` carried the Runbooks convention, git-identity rules, and
  merge-authority policy — all generic doctrine with nothing mmio-specific
  in it once inspected (the only per-repo content was the old bot name,
  which goes away entirely now that every migrated repo shares one App).
  With those sections gone, nothing was left in the file, so it was
  deleted. `CLAUDE.md`'s `@AGENTS.md` import was replaced with a direct
  top-level import of the canonical doc:
  `@~/.claude/LIFEOS/DOCUMENTATION/BotIdentity/BotIdentitySystem.md`.

## Verification

- `bash ~/.claude/hooks/tests/BotIdentity.test.sh` — 31 passed, 0 failed.
- `bash ~/.claude/hooks/tests/BotIdentityVerify.test.sh` — 8 passed, 0
  failed.
- This PR's first commit landed as `mccarthycode-claude-agent[bot]` via the
  shared hook, and the PR itself was opened via `gh-bot pr create`, proving
  both halves of the shared machinery end to end on this repo.

Merge is the principal's call, not automated here.
