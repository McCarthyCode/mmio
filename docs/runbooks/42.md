# Runbook: Serve the site as an App Platform static site (#42)

## What this is

Production moves from a billed App Platform service (Gunicorn in the
Dockerfile image) to a free-tier static site. `app/freeze.py` renders every
Flask route plus `static/` to `app/build/` at build time, and `app.yaml`
publishes that directory as a `static_sites` component.

## Adding a route

Add it to `PAGES` in `app/freeze.py`. A route that isn't listed there won't
exist in production. A listed route that doesn't return 200 fails the build.

## CSP

App Platform static sites can't set response headers, so the
Content-Security-Policy is a `<meta http-equiv>` tag at the top of
`app/templates/index.html`. Any new third-party script, style or font host
has to be added there.

## Applying the change

Merging this PR does **not** switch production. App Platform rebuilds on push
against the spec it has stored and doesn't read `app.yaml` from the repo. Until
the spec is applied, it keeps building the old Dockerfile service from the new
code, which still works (the CSP is enforced by the meta tag) but stays billed.

After merging:

1. Save the current spec for rollback:
   `doctl apps spec get <app-id> > app.service.yaml` (keep it out of the repo).
2. `doctl apps spec validate app.yaml`
3. `doctl apps update <app-id> --spec app.yaml`

Untested: whether App Platform accepts changing component `www` from a service
to a static site in place. If it rejects the update, rename the static site
component (for example `site`), point the last ingress rule's `component.name`
at the new name, and apply again.

## After the spec is applied

1. Watch the App Platform deploy. The build log should list all 8 pages
   from `freeze.py`.
2. Check `https://mattmccarthy.io/`, `/robots.txt`, `/llms.txt` and
   `/sitemap.xml`. Check that `mattmccarthy.net` still 301s to
   `https://mattmccarthy.io`.
3. Open the browser console on the homepage and confirm there are no CSP
   violations.
4. Confirm in billing that the app now shows as a free static site.

## Rollback

Re-apply the saved service spec: `doctl apps update <app-id> --spec app.service.yaml`.
Reverting #42 alone does not restore the service, for the same reason merging
doesn't switch it. Revert as well if you want the repo to match.

## Python version

Not pinned. App Platform's Python buildpack defaults to 3.14.x. `freeze.py` was
checked on Python 3.13, 3.14 and 3.15 slim images. A pin has to name a patch
version the buildpack supports, and a wrong one fails the build, so it's left
at the default.
